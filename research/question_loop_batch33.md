## I225: Prior Art Absorption Test

### Single Most Dangerous Question

Is FrameSeed anything more than machine teaching, teaching dimension, active learning with counterexamples, CEGIS-guided curriculum, or program-synthesis library learning with a better slogan?

### Attack

Specific prior art/systems FrameSeed must beat or differentiate from:

| Line | Representative works/systems | Absorption pressure |
|---|---|---|
| Teaching dimension | Goldman and Kearns 1995; Shinohara and Miyano; recursive teaching dimension work by Zilles/Lange/Holte/Zinkevich | Minimal examples identifying a target concept are the obvious version of "intelligence vaccines." |
| Machine teaching | Zhu 2013 and later optimal teaching work for Bayesian/linear learners | Designing training examples for a known learner is the direct ancestor. |
| Query/active learning | Angluin 1987 L*; membership/equivalence queries; query-by-committee; Settles survey | Counterexamples and decisive queries are not new. |
| CEGIS/SyGuS/PBE | Solar-Lezama SKETCH/CEGIS; Alur et al. SyGuS; FlashFill/PROSE | Examples plus counterexamples plus verifier equals standard synthesis. |
| Curriculum learning | Bengio et al. 2009; self-paced learning | Ordered lessons that make learning easier are already a field. |
| Library/meta-learning | DreamCoder; Bayesian Program Learning; MAML-style adaptation | Reusable abstractions that reduce future sample complexity already exist. |

The strongest absorption is simple:

```text
Given learner L and concept class H, FrameSeed is an optimal teaching set or
teaching policy for L over H.
```

If that is the whole claim, kill it now.

### Control Or Redirect

Add these baselines to FRAMESEED-0:

```text
Optimal Teaching Set Baseline: shortest packet identifying the target for the
same learner, same hypothesis class, same packet channel, same hidden eval.

Teaching Dimension Solver: exact or approximate minimal teaching set for the
supplied concept class.

CEGIS Teaching Baseline: counterexamples generated by a standard CEGIS loop.

Library Learning Baseline: DreamCoder-like or MDL macro learner gets the same
tasks and may invent the same reusable frame.
```

## I226: Frame vs Selection Attack

### Single Most Dangerous Question

How do we know the learner did not already contain the frame primitive, so the vaccine merely selected the right pre-existing hypothesis?

### Attack

This is the central fatal confound. If the learner has a Boolean DSL containing `XOR`, and the target is parity, a packet that makes it pick `XOR` did not transmit a frame. It selected a hypothesis. If the learner has feature masks, and the target is "ignore nuisance fields," the packet selected a subset. If the learner has invariance predicates, and the target is an invariant, the packet selected a predicate.

Worse:

```text
Any sufficiently expressive DSL technically contains the target.
```

Therefore "the learner does not already know the frame" cannot mean literal non-expressibility. It must mean resource-bounded non-containment.

Define the pre-packet learner:

```text
L0 = (R0, H0, A0, B0)
```

where `R0` is representation language/primitives, `H0` is the reachable hypothesis family, `A0` is the update procedure, and `B0` is packet length, query count, search depth, runtime, and description budget.

A frame `F` is not already known only if all hold:

```text
1. Bounded non-reachability:
   No h in Reach(L0, public data, B0) achieves hidden-family threshold.

2. No low-cost named primitive:
   R0 contains no primitive, feature, role name, verifier, or transformation
   whose semantics are isomorphic to F under role permutation.

3. No equivalent teaching set:
   The optimal teaching set over H0 under B0 cannot induce hidden-family
   transfer at comparable packet length.
```

A true T3-R packet must do at least one of:

```text
1. Extend R0 with a reusable operator, verifier, transformation, or
   decomposition that was not low-cost in R0.
2. Change the search metric so the correct family becomes reachable under B0.
3. Add a local test/intervention generator that distinguishes hidden families
   indistinguishable to L0.
4. Compile a reusable macro whose amortized cost over multiple hidden tasks is
   lower than teaching each task separately.
```

Selection is causing `L0` to choose `h in H0` without changing representation, intervention language, verifier set, or future task sample complexity. Transmission is changing the learner's operational interface to the family and reducing future hidden-task teaching cost after the target task is removed.

### Control Or Redirect

Run a pre/post representation test:

```text
Before packet:
  Freeze L0. Give it public data, active queries, CEGIS counterexamples, and
  optimal teaching-set budget. It must fail hidden transfer.

Packet:
  Apply P, but P may not contain target role names or answer labels.

After packet:
  Evaluate on the target task and at least two sibling tasks requiring the same
  frame but different surface functions.
```

Run packet-erasure ablations:

```text
Remove examples but keep the proposed operator/verifier.
Remove operator/verifier but keep examples.
Permute names and roles after packet construction.
Swap nuisance field positions after packet construction.
```

Transmission requires: operator/verifier present plus limited examples passes; examples only fails; operator/verifier helps sibling tasks; role permutation preserves the verdict.

### Feed Into Work Loop

W25 must add a `Representation-Noncontainment Contract` listing available primitives, forbidden target-isomorphic primitives, search/description budget, allowed packet additions, sibling tasks, and ablations.

### Verdict + Next Gate + Kill Records

```text
FRAMESEED SURVIVES ONLY AS T3-R.
```

Next-gate ranking:

1. Representation-noncontainment certificate.
2. Sibling-task transfer.
3. Packet-erasure ablation.

Kill records:

```text
KR-I226-1: If the target frame exists as a low-cost primitive or feature mask in
the learner prior, emit FRAMESEED_T3_ABSORBED_BY_REPRESENTATION_PRIOR.

KR-I226-2: If post-packet success does not improve sibling-task teaching cost,
emit FRAMESEED_T3_SELECTION_NOT_TRANSMISSION.

KR-I226-3: If examples-only ablation matches the full packet, emit
FRAMESEED_T3_ABSORBED_BY_TEACHING_DIMENSION or FRAMESEED_T3_ABSORBED_BY_RAG.
```

### NARRATIVE ATTACK

**Strongest "that's obvious" dismissal:** You did not teach the model a new way to think. You gave it a hint that picked the right option from a menu it already had.

**Strongest "that's trivial" dismissal:** If XOR is in the DSL, teaching parity is selecting XOR. If masks are in the DSL, teaching invariance is selecting a mask.

**What the result needs to be:** the packet creates a reusable operational affordance: a new test, macro, verifier, decomposition, or transformation that reduces future teaching cost on sibling tasks after original target labels are gone.

## I227: Nuisance Growth Trick Attack

### Single Most Dangerous Question

Is the compactness gap real, or is it rigged because the vaccine packet is architecturally allowed to ignore nuisance while baselines are forced to learn or reconstruct it?

### Attack

B32 inherited a PCCP-H idea:

```text
Functional frames can ignore nuisance entropy, while reconstruction proxies pay
Omega(m).
```

FrameSeed can abuse this. If the vaccine packet has a privileged channel for "only attend to C fields," "ignore N fields," "this is the causal intervention," or "this is the invariant," while baselines receive flat examples, the scaling curve is a format advantage. The reviewer says: your vaccine stayed compact because you hard-coded the skip around nuisance; your baselines grew because you made them solve a different problem.

### Control Or Redirect

All baselines must be allowed to ignore nuisance. Add a nuisance-oracle fairness suite:

```text
O0: Oracle causal-mask baseline
    Gets the true non-nuisance coordinates but not the target rule.

O1: MDL feature-subset baseline
    Searches feature subsets and functions under the same description budget,
    optimizing hidden-family function, not reconstruction.

O2: Invariant active learner
    Can query interventions designed to reject nuisance dependence.

O3: CEGIS with nuisance-ignoring objective
    Minimizes functional error and program length, no reconstruction penalty.

O4: Randomized nuisance relabeling
    Nuisance bits are resampled across equivalent cases so every method can
    detect non-use statistically.
```

The fair objective is shortest packet that induces hidden-family functional correctness, not shortest packet that reconstructs observed records. Measure `L_vaccine(m)`, `L_teaching(m)`, `L_active(m)`, `L_cegis(m)`, `L_oracle_mask(m)`, and `L_library(m)`.

Success cannot be "vaccine constant, reconstruction grows." That was already PCCP-H. Success must beat function-aligned nuisance-ignoring baselines or show reusable frame amortization on sibling tasks.

### Feed Into Work Loop

W25 must add:

```text
Nuisance Fairness Clause:
  No baseline may be forced to reconstruct nuisance bits. All baselines optimize
  hidden-family functional accuracy and description/query cost.
```

### Verdict + Next Gate + Kill Records

```text
The nuisance-growth story is currently weak.
```

It survives only after nuisance-ignoring baselines are allowed. If the only gap is against reconstruction or raw RAG, it is not a FrameSeed result.

Next-gate ranking:

1. Oracle causal-mask baseline.
2. Function-only MDL baseline.
3. Nuisance randomization.

Kill records:

```text
KR-I227-1: If an oracle causal-mask baseline matches the vaccine, emit
FRAMESEED_T3_ABSORBED_BY_NUISANCE_ORACLE.

KR-I227-2: If the gap exists only against reconstruction baselines, emit
FRAMESEED_T3_VOID_BAD_BASELINE.

KR-I227-3: If compactness depends on packet fields that encode "ignore
nuisance," emit FRAMESEED_T3_VOID_SMUGGLED_FRAME.
```

### NARRATIVE ATTACK

**Strongest "that's obvious" dismissal:** Of course the short lesson wins if it is told which fields matter and the other methods are punished for looking at all fields.

**Strongest "that's trivial" dismissal:** You compared a causal mask to a lookup table. The mask wins because the task was designed so the mask wins.

**What the result needs to be:** it must beat baselines that can ignore nuisance by construction, search for causal masks, and optimize only the functional target. The remaining edge must come from reusable frame transfer.

## I228: Boolean Toy Trap

### Single Most Dangerous Question

What is the minimum second domain that would prove FrameSeed is not another Boolean enumeration project, and how fast must the repo get there?

### Attack

PCCP-H died inside Boolean toy worlds because every "discovery" could be absorbed by finite enumeration over human-supplied grammars. FrameSeed can easily repeat the pattern:

```text
Boolean bits -> hidden causal bits -> nuisance bits -> parity/invariance ->
active examples -> tiny DSL -> positive result.
```

A hostile reviewer will not care that the controls are cleaner if the world is still a Boolean puzzle. The story is cheap useful intelligence for ordinary people. Boolean parity with nuisance fields is not that story.

### Control Or Redirect

The minimum second domain must satisfy:

```text
1. Non-Boolean typed objects: strings, numbers, lists, records, IDs, dates,
   units, or actions.
2. Realistic frame: identity is stable under renaming; units normalize before
   comparison; row order is not object identity; foreign keys define joins;
   selectors bind to semantics rather than surface labels.
3. Hidden-family transfer: schemas, names, arities, units, and nuisance columns
   change after packet construction.
4. Fair baselines: active learning, CEGIS, RAG, teaching dimension, nuisance
   oracle, and library learning get equal information.
5. Usable narrative: a cheap local agent learns a practical data/tool-use frame
   from a tiny lesson.
```

Recommended minimum domain:

```text
FRAMESEED-SHEETS-0:
  Tiny spreadsheet/data-cleaning/task automation world.

  Candidate frames:
    - match entities by stable ID, not display name;
    - normalize units before aggregation;
    - join by key, not row position;
    - validate constraints before applying an action.

  Hidden transfer:
    - renamed columns;
    - nuisance columns;
    - shuffled rows;
    - new unit systems;
    - missing aliases;
    - adversarial display names.
```

This is better than ARC/gridworld as the first escape because spreadsheet/tool frames are closer to the poorest-person usefulness target: local automation that avoids expensive cloud AI.

## I229: Teaching Dimension Prior Art

### Single Most Dangerous Question

Does the proposed T0-T5 teaching ladder merely rename existing teaching-dimension theory?

### Attack

The B32 ladder maps onto prior art more tightly than the direction-finding pass admitted:

| FrameSeed level | Prior-art absorption |
|---|---|
| T0 rote examples | Supervised examples, few-shot, memorization. |
| T1 active curriculum | Teaching dimension, optimal teaching sets, active learning, curriculum learning. |
| T2 counterexample-guided patch | CEGIS, equivalence-query learning, program repair. |
| T3 vague frame-bearing lesson | Machine teaching with richer instances, representation learning, invariant teaching, feature construction, library learning. |
| T4 self-generating frame teacher | Active machine teaching, experiment design, meta-learning teachers, library-learning loops. |
| T5 open-world frame formation | Scientific discovery/program synthesis with invented DSLs. Not solved here. |

So T0-T4 are not a new ladder unless the boundaries are sharpened around what prior art does not claim.

### Control Or Redirect

The actual theoretical object worth defining is not "vaccine." It is:

```text
Frame Teaching Dimension (FTD):
  minimum packet length needed to transform learner L0 into L1 such that L1
  reaches threshold T on hidden family E under budget B, while no optimal
  teaching set over L0's original hypothesis class reaches T at comparable
  length.

Amortized Frame Teaching Dimension (AFTD):
  total packet cost to install a reusable frame divided by the number of sibling
  tasks solved with reduced teaching cost.
```

T3-R should require:

```text
A packet reduces amortized teaching cost across at least k >= 3 sibling hidden
tasks by adding or exposing a reusable representation component not reachable
under L0's prior budget.
```

Then compare:

```text
AFTD(frame packet) versus sum of TD(task_i) for independent optimal teaching
sets, and versus MDL/library-learning total description length.
```

If the packet does not produce an amortized advantage, it is just teaching dimension.

### Feed Into Work Loop

W25 must add:

```text
Formal Object:
  Frame Teaching Dimension and Amortized Frame Teaching Dimension.

Primary metric:
  AFTD gap against independent optimal teaching sets and library-learning MDL.
```

### Verdict + Next Gate + Kill Records

```text
T0-T2 are absorbed.
T3 vague is absorbed.
T3-R with amortized reusable representation remains alive.
```

Next-gate ranking:

1. AFTD definition.
2. Sibling-task amortization.
3. Independent teaching-set comparison.

Kill records:

```text

FRAMESEED_T3_VOID_T3_UNDEFINED.

KR-I229-2: If the packet only identifies one concept and does not reduce

KR-I229-3: If library learning achieves the same amortized description length,
```

**Strongest "that's trivial" dismissal:** T0 through T4 are a survey table. The only new item, T5, is not implemented.

**What the result needs to be:** an amortized frame-teaching gap: one compact packet reduces the teaching cost of a family of future tasks in a way independent optimal teaching sets and library learners do not match.

## I230: Strongest Positive Scenario

### Single Most Dangerous Question

If FRAMESEED-0 works perfectly, what is the most we can honestly claim, and is that claim worth the batches?

### Attack

A perfect hardened result would show:

```text
1. Frozen L0 cannot solve hidden-family tasks under public data, active query,
   teaching-set, CEGIS, RAG, nuisance-oracle, and library-learning budgets.
2. Compact packet P, without target names or answer-shaped primitives,
   transforms L0 into L1.
3. L1 solves the hidden target and at least two sibling tasks requiring the same
   frame.
4. Packet length stays flat or sublinear under nuisance growth.
5. Removing the frame component breaks sibling transfer.
6. Role/name permutation preserves the verdict.
7. Function-aligned baselines require at least 4x cost to match, or fail.
```

The most honest claim would be:

```text
In a controlled finite domain, compact representation-changing packets can
reduce amortized teaching cost across a hidden task family under strict
absorption controls.
```

Do not claim that AI has been made cheap, intelligence vaccines work generally, scale has been defeated, or a new theory of intelligence has been found. Claim only that a measurable object exists: the amortized cost of transmitting a reusable frame to a bounded learner.

### Control Or Redirect

Run FRAMESEED-0 as a kill gate, not as a victory path:

```text
Gate 1: Does T3-R exist in a minimal world?
Gate 2: Does the same packet idea survive in FRAMESEED-SHEETS-0?
Gate 3: Does failure generate a local patch packet that composes with the first

```

If Gate 1 passes but Gate 2 fails, the result is a toy-only frame-teaching signal, not a moonshot.

## I231: Final Pre-Test Verdict

### Single Most Dangerous Question

Given all attacks, should FrameSeed be implemented, or should the project redirect before spending W-loop batches?

### Attack Synthesis

FrameSeed's strongest claim is threatened from four sides:

```text
1. Prior art:
   Machine teaching and teaching dimension already cover compact lessons for
   known learners.

2. Learner prior:
   The "frame" may already exist as a primitive, feature, mask, verifier, or
   DSL expression.

3. Nuisance unfairness:
   The compactness curve may be a rigged comparison against reconstructive or
   raw-example baselines.

4. Toy absorption:
   Boolean worlds make every result vulnerable to finite enumeration and
   supplied-grammar absorption.
```

The original FrameSeed story is not strong enough. The hardened version remains worth a short implementation window because it targets a real missing object:

```text
Can a compact packet change a cheap learner's reusable representation so that
future task-family teaching cost drops under fair baselines?
```

That still serves the manifesto: cheap intelligence as shared, inspectable, portable structure rather than more training data.

### Control Or Redirect

The one required modification is:

```text
T3-R: Representation-Changing Frame Transfer

A packet P is T3-R only if:
  1. L0's prior representation and hypothesis class fail a documented
     representation-noncontainment certificate under budget B0.
  2. P does not contain target role names, answer labels, or target-isomorphic
     low-cost primitives.
  3. Applying P creates or exposes a reusable operator, verifier,
     transformation, decomposition, intervention generator, or search metric.
  4. The post-packet learner improves hidden transfer on at least two sibling
     tasks requiring the same frame.
  5. Independent optimal teaching, active learning, CEGIS, RAG, nuisance-oracle,
     and library-learning baselines fail or require at least 4x cost.
  6. Packet-erasure, role permutation, and nuisance-growth ablations preserve
     the interpretation.
```

This is the single modification that makes FrameSeed hardest to absorb.

If FrameSeed fails under these gates, do not retreat to a safer curriculum-learning project. Redirect to the higher-risk sibling:

```text
Self-Discovered Transformation Grammars in typed practical domains:
Can a cheap system discover which transformations are valid in a new typed
domain without being handed the transformation grammar?
```

Why: if frame transfer collapses into teaching dimension, the deeper hard problem is frame creation.

```text
2. Representation-noncontainment certificate.
3. AFTD metric.
4. Prior-art absorption baselines.
5. Nuisance-oracle fairness baselines.

```


Next-gate ranking:

2. Can FRAMESEED-0 produce T3-R under prior-art and nuisance-oracle baselines?
3. Can FRAMESEED-SHEETS-0 replicate outside Boolean toys by W29?


### NARRATIVE ATTACK

**Strongest "that's obvious" dismissal:** The whole thing says "teach the right abstraction." Human teachers, curriculum learning, machine teaching, and program synthesis already do this.

**Strongest "that's trivial" dismissal:** FrameSeed will build a puzzle where the solution is a compact rule, provide a packet format that can express that rule, and show the packet beats dumb examples. That is benchmark design.

**What the result needs to be:** a hostile-baseline-resistant, representation-changing, amortized frame-teaching separation that leaves Boolean toys quickly and teaches a practical typed frame. The public story becomes unkillable only when a reader sees a cheap local agent gaining a reusable way to reason from a tiny packet that optimal teaching and synthesis baselines could not cheaply reproduce.
