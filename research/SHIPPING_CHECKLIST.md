# Shipping Checklist: Eklavya Embedding Model

**Goal:** Ship a small, useful embedding model on HuggingFace — not a toy.

## 1. Minimum Competitive Bar

Target: beat all-MiniLM-L6-v2 (MTEB ~56.3) at comparable size.
Stretch: match nomic-embed-text-v1.5 (~62) or bge-small-en-v1.5 (~60).

| Metric | Floor | Competitive | Stretch |
|--------|-------|-------------|---------|
| MTEB avg (56-task English) | >56 | >60 | >63 |
| Retrieval nDCG@10 (15 tasks) | >45 | >50 | >52 |
| STS avg | >78 | >82 | >84 |
| Classification avg | >65 | >70 | >72 |
| Params | <100M | <50M | <30M |

If the model can't beat MiniLM-L6 on MTEB avg, don't ship it as a model.
Ship the methodology paper instead.

## 2. What Makes It "Eklavya"

The model card must honestly answer: **what did the teachers contribute
that the student could not learn alone?** Specifically:
- Name the teachers and what each contributed
- Show the control: same student, same data, no teachers
- Show retained gain: teacher access removed at inference
- Show probe contribution: probes vs identity-only KD

Without this, it's just another distilled model.

## 3. sentence-transformers Integration (Required)

- Save with `model.save_pretrained()` or `model.push_to_hub()`
- Include `modules.json` so SentenceTransformer auto-loads
- Ensure `model.encode()` works out of the box
- Include pooling config (`1_Pooling/config.json`)
- Support `trust_remote_code=False` (no custom code needed)

## 4. MTEB Evaluation (Required Before Ship)

Run the full English MTEB (56 tasks, ~2-4 hours on GPU):
```
mteb run -m <model_path> --task_types retrieval classification sts \
  clustering reranking pair_classification summarization
```
Submit results to the MTEB leaderboard via HuggingFace.

## 5. Model Card (Required)

Auto-generated by sentence-transformers, but manually add:
- **Eklavya section:** teachers used, tomography method, retained gain
- **Intended use:** what it's good/bad at
- **Limitations:** where teachers were weak, the student inherits those gaps
- **Training details:** data sources, compute budget, training time
- **Comparison table:** vs MiniLM-L6, bge-small, nomic-embed

## 6. ONNX + Quantization (Ship Day)

```bash
optimum-cli export onnx --model <path> onnx_model/
optimum-cli onnxruntime quantize --avx512 onnx_model/ onnx_model_quantized/
```
- Export FP32 ONNX model
- Quantize to INT8 (dynamic quantization)
- Test: quantized MTEB score within 1 point of FP32
- Upload both to the same HuggingFace repo

## 7. Matryoshka Dimensions (Nice to Have)

Train with matryoshka loss so users can truncate embeddings:
- Full dim (e.g., 384)
- 256, 128, 64
- Report MTEB at each dimension in the model card

## 8. Ship Sequence

1. Beat MiniLM-L6 on MTEB avg (the floor)
2. Write model card with Eklavya provenance
3. Push to HuggingFace with sentence-transformers format
4. Export ONNX + INT8 quantized
5. Submit to MTEB leaderboard
6. Write a short blog post: "A 30M model that learned from 3 teachers"
