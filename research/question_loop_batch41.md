## Executive Verdict

The next moonshot direction should be:

```text
WORLD GRAMMAR DISCOVERY (WGD):
cheap systems discover reusable transformation and obligation grammars from
opaque typed worlds, rather than receiving those grammars as packets, operation
names, schemas, exact bindings, or hand-authored verifier templates.
```

This subsumes the strongest surviving FrameSeed reframe, self-discovered transformation grammars, but hardens it. A transformation grammar alone can still be absorbed by PBE, CEGIS, MDL library learning, schema matching, or active learning. WGD asks for the larger discovered object:

- valid, invalid, unsafe, and goal-relevant transformations;
- invariants that must be preserved;
- verifier obligations that make failures repairable;
- abstention conditions under ambiguity;
- local repair operations;
- composition rules that transfer to held-out siblings.

If real, WGD serves all five sacred outcomes: genuine intelligence through meaning-aware action, improvability through local obligations, democratized development through inspectable executable grammar, data efficiency through cross-task reuse, and inference efficiency through compiled constraints instead of repeated search.

## I323: Attack The Obvious Continuation

### Attack

The milestone says self-discovered transformation grammars are the only serious escape. That is right but under-specified. The phrase can be faked by giving the learner named operations, typed APIs, exact bindings, and verifier templates, then saying the learner discovered a grammar over designer-supplied primitives.

### Verdict

```text
SELF-DISCOVERED TRANSFORMATION GRAMMARS IS NOT SAFE AS STATED.
IT MUST BE HARDENED AGAINST SUBSTRATE-SMUGGLED FRAME TRANSMISSION.
```

## I324: Attack The Overcorrection

### Attack

Removing all structure is not rigor. If the learner receives raw chaos, arbitrary scoring, and hidden semantics, every outcome becomes void. Frame discovery needs a bounded public substrate; it just cannot receive the target grammar, operation ontology, verifier templates, or solved bindings.

### Verdict

```text
BOUNDED DISCOVERY, NOT MYSTICAL INDUCTION FROM NOTHING.
```

## I325: Attack Typed Practical Domains

### Attack

Typed practical worlds are dangerous because tables imply joins, units imply normalization, IDs imply entity resolution, dates imply interval logic, and constraints imply repair. SHEETS-0 already showed that public typed substrate can carry the frame.

### Counterattack

Rejecting practical domains would dodge the Vision. Use practical typed worlds, but make the hidden object the latent transformation and obligation grammar, not a named operation family.

### Verdict

```text
USE TYPED PRACTICAL WORLDS ONLY IF THE OPERATION ONTOLOGY IS NOT GIVEN.
```

## I326: Attack Grammar Discovery As Program Synthesis In Costume

### Attack

A system can observe examples, synthesize programs, compress repeated subprograms into macros, and call the macro library a world grammar. That is not a WGD win if MDL library learning solves at matched or lower all-in cost.

### Verdict

```text
MDL LIBRARY LEARNING IS THE FIRST ABSORBER, NOT A WEAK BASELINE.
WGD SIGNAL REQUIRES OBLIGATIONS, INVALIDITY, ABSTENTION, REPAIR, AND TRANSFER.
```

## I332: Define WGD Without Smuggling The Win

### Attack

"World Grammar Discovery" sounds broader than a first experiment can justify. Narrow it until a hostile reviewer can falsify it.

### Definition

```text
Given raw typed observations, black-box outcome feedback, and a minimal action
proposal interface, can a cheap learner infer a compact executable grammar of
valid, invalid, unsafe, and goal-relevant transformations that transfers to
held-out tasks and siblings while native synthesis, schema, causal, active, and
library baselines fail or pay >=4x all-in?
```

The output must be executable and inspectable: transformations, invariants, obligation predicates, counterexample requests, abstention conditions, local repair operators, composition rules, and residual uncertainty.

### Verdict

```text
WGD-0 IS A NARROW EXECUTABLE DISCOVERY CLAIM, NOT A GENERAL-INTELLIGENCE CLAIM.
```

## I334: First Test Sketch

### Attack

The first test can fail by being too vague. Use opaque typed state-transition worlds: records, fields, events, constraints, and black-box outcome feedback, but no published operation families such as join, normalize, dedupe, validate, aggregate, or repair.

Public information: raw before/after states, failed/successful action traces without latent operation labels, primitive typed equality/order/containment tests, a finite action-proposal serialization, black-box feedback, and training/sibling worlds.

Hidden information: latent transformation families, obligation predicates, unsafe-action conditions, binding solution, composition rules, held-out permutations, held-out siblings, hidden query mix, and scoring.

Systems output: executable grammar, valid/invalid/unsafe transformation predictions, obligations, abstention, local repairs, held-out answers, and cost ledger.

Signal requires held-out HFA >=0.95, sibling HFA >=0.90 on >=3 reduced siblings, obligation F1 >=0.90, invalid/unsafe detection >=0.90, local repair >=0.80, AFTD_all_in pass, every native absorber failing or paying >=4x, and no supplied-ontology or leakage absorber.

### Verdict

```text
WGD-0 CAN BE MADE MEASURABLE WITHOUT HANDING OVER THE GRAMMAR.
THE SPEC MUST PRECEDE THE HARNESS.
```

## I335: Attack WGD-0 Before It Becomes Doctrine

### Attack

WGD-0 can still fail through generator bias, impossible hidden worlds, typed primitives that imply ontology, black-box feedback that becomes active labeling, arbitrary hidden obligation labels, proxy baselines, or LLM priors importing real-world semantics denied to symbolic systems.

### Countermeasures

If native baselines are not implemented, token is `WGD_INCONCLUSIVE_BASELINES_NOT_NATIVE`. If operation labels or verifier templates are public, emit supplied-ontology absorption. If grammar labels are not behaviorally identifiable, no obligation claim is allowed. If LLM priors are used, run a no-language symbolic condition and charge the model prior. If active feedback isolates the grammar, emit active-learning absorption. If public statistics predict grammar family, emit generator-leakage absorption.

### Verdict

```text
WGD IS WORTH STARTING ONLY BECAUSE IT CAN BE KILLED CLEANLY.
IF IT CANNOT BE KILLED CLEANLY, DO NOT START.
```
