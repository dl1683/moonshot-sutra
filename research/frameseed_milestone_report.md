## What Was Absorbed

### Packet As Teaching Set

In the Boolean world, the packet's useful content reduced to finite support/search information that exact teaching dimension and brute-force two-slot truth-table search already explain.

```text
The packet identifies the right small finite hypothesis; it does not transmit a new reusable representation that lower baselines cannot reach.
```

That explanation fits the measured facts and matches the Q-Loop B33 warning that compact frame-bearing lessons are already close to machine teaching.

### Typed Packet As Schema Binding And Pipeline Synthesis

In SHEETS-0, the useful work was in charged task bindings and typed pipeline synthesis, not reusable frame transfer.

```text
binding-only HFA = 1.0
packet-erasure drop = 0.0
AFTD_all_in_passed = false
composition_gate_passed = false
```

The packet frame was not the active ingredient. Once bindings and the typed operator substrate were visible, ordinary spreadsheet/data-transformation machinery solved the hidden tasks.

### Current FrameSeed Narrative

The phrase compact frame packet is not yet a distinct scientific mechanism. In the tested versions it decomposes into known objects:

- optimal teaching sets;
- counterexample-guided search;
- active disambiguation;
- schema binding;
- typed program synthesis;
- PBE/table transformation;
- data-wrangling recipes;
- typed library learning.

The result does not say portable teaching is useless. It says FrameSeed has not shown a non-absorbed moonshot mechanism.

## What Was Learned

1. Perfect hidden HFA is not signal. Both L3 systems reached perfect hidden-family accuracy and both were still absorbed.
2. Packet compactness is not enough. Compactness does not rescue the claim if the compact object is only a teaching set, binding list, or executable pipeline hint.
3. Packet-erasure is decisive. In SHEETS-0, removing the packet did not hurt once bindings remained.
4. AFTD is the right pressure point. The milestone did not produce a passing amortized frame-teaching gap.
5. Q-Loop B33 was directionally right. It predicted that unmodified FrameSeed is inside machine teaching, teaching dimension, active learning, CEGIS, synthesis, and library learning unless representation noncontainment plus amortized sibling transfer survives.
6. The methodology is the strongest artifact: precommit, hidden-open discipline, token precedence, equal-information absorbers, cost ledgers, audits, ablations, and claim ceilings.

## Does Any Reframing Escape Absorption?

### Try Harder Domains

Not enough. A harder domain may delay simple enumeration, but SHEETS-0 already moved into a typed practical domain and was absorbed by methods native to that domain. A domain change alone does not escape absorption.

### Make L3 More Powerful

Disallowed as a rescue. A richer L3 would likely make the packet solve more tasks, but if L3 gets more typed semantics, synthesis power, verifier power, or parser power, the baselines must get equal executable information. The result would probably move toward PBE, CEGIS, library learning, or representation-prior absorption.

### Use Natural-Language Packets

Disallowed as a signal path. Natural language risks hiding the frame in semantic priors that are hard to count and hard to share with baselines. It weakens adversarial clarity.

### FrameSeed As Curriculum Engineering

Scientifically honest, but not a moonshot. FrameSeed can be reframed as compact lessons, audits, or curricula for known learners. That may be useful engineering, but it does not escape machine teaching or program synthesis.

### Self-Discovered Transformation Grammars

This is the only serious escape route. The tested FrameSeed supplied the frame. The surviving hard problem is frame discovery:

```text
Can a cheap system discover which transformations, invariants, verifiers, bindings, or grammars are valid in a new typed domain without being handed the transformation grammar or task bindings?
```

This is not a tweak. It changes the object from transmitting a compact packet to discovering the frame-generating grammar or validity structure. It must still preserve the same methodology: precommit the target, deny hidden semantics, share public substrate with baselines, run synthesis/library/schema/active/oracle absorbers, count human-authored substrate separately, and require held-out transfer.

## Direction Assessment

FrameSeed should not continue as the main moonshot direction in its current form. Two domains tested. Two absorptions. The hard clock did what it was supposed to do.

The next direction should be chosen from the allowed reframes in the specs, with preference for the one that attacks frame creation rather than frame transmission:

```text
Self-discovered transformation grammars in typed practical domains.
```

A concrete next question:

```text
Given opaque typed tables, public operations, and hidden held-out obligations, can a cheap learner infer a reusable transformation/verification grammar that survives schema, unit, row, name, and task-family shifts, while PBE, typed CEGIS, library learning, schema binding, and active goal disambiguation receive equal information and fail or pay >=4x?
```

This still may be absorbed by typed CEGIS or library learning. That is acceptable. The point is to test the deeper problem honestly.

Alternate acceptable redirects:

- typed CEGIS/proof compilation as the honest substrate;
- MDL library learning as the honest substrate;
- active counterexample selection as the honest substrate;
- schema-binding science as the honest substrate.

These are redirects, not FrameSeed victories. If the project chooses one, it should name it plainly and precommit the absorber ladder before implementation.

## Methodology To Preserve

1. Precommitted terminal tokens before implementation.
2. Absorber-first design: strongest boring explanations become executable.
3. Equal-information baseline parity.
4. Hidden-open discipline.
5. Packet-erasure and ablation tests.
6. Role/schema/name/unit/row permutation stability.
7. Cost splits for frame, binding, program, parser substrate, human labor, and residual teaching bits.
8. AFTD-style amortization for any claimed reusable frame.
9. Strict claim ceilings.
10. Negative results as primary research output when they remove a real assumption.
