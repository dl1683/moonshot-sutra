# PCCP-H Theorem Draft: Interventional Functional Compression Separation

**Date:** 2026-07-07
**Status:** Draft mathematical artifact for W-Loop B20
**Scope:** finite worlds only; pure mathematics; no experiments; no training

This document proves the first finite-world theorem package for PCCP-H. The theorem-bounded claim is:

```text
Surface reconstruction and observational evidence are not the same objective as interventional function preservation. In finite worlds, the gap can grow linearly with nuisance entropy.
```

This does not prove that PCCP-H is a new synthesis algorithm, or that it beats CEGIS, ILP, DreamCoder, symbolic regression, causal discovery, spec mining, or neural-tool agents. It proves a separation between observational/surface reconstruction and verified interventional functional compression.

---

## 0. Formal Setup

All sets are finite. A distribution on finite set `T` is a function `p:T -> [0,1]` with `sum_t p(t)=1`. For bit vectors `a,b in {0,1}^m`, let `d_H(a,b)` be Hamming distance. All logarithms are base 2.

### 0.1 Finite SCM

A finite deterministic structural causal model is

```text
w = (U, Z, E, P_U)
```

where `U=(U_1,...,U_r)` are exogenous variables over finite domains, `P_U` is a distribution over `U`, `Z=(Z_1,...,Z_s)` are endogenous variables over finite domains, and `E=(E_1,...,E_s)` are deterministic structural equations. For this draft the equations are acyclic, so each `E_j` depends only on `U` and earlier endogenous variables. For exogenous assignment `u`, write the unique endogenous assignment as `z_w(u)`.

An intervention `i` replaces one or more structural equations by constants or new deterministic equations. `do(T:=t)` replaces the equation for `T` by the constant `t`. Counterfactual evaluation holds the factual exogenous assignment fixed. The explicit constructions below use observations with a unique relevant exogenous assignment.

### 0.2 Observation Encoder

For world `w`, observations are generated by

```text
X = Obs_w(Z, N, S)
```

where `Z` are endogenous causal variables, `N` are nuisance variables whose changes should not change the target decision, and `S` are spurious variables that may correlate with the target observationally but are not target causes. `N` and `S` may be endogenous, exogenous, or observation-side surface variables. The only requirements are finite domains and a specified target role.

The observational distribution is

```text
P_obs^w(x) = Pr_{u ~ P_U}[Obs_w(z_w(u),N_w(u),S_w(u)) = x].
```

### 0.3 Target Function

Let `Q` be a finite query set, `I_int` a finite intervention set, and `Y` a finite decision set. The target function is

```text
F_w : X_w x Q x I_int -> Y.
```

`F_w(x,q,i)` is the decision requested by query `q` after applying intervention `i`. In Part 1 it is the counterfactual value of a designated endogenous variable after holding fixed the factual exogenous assignment.

### 0.4 PCCP Artifact

The core PCCP artifact is

```text
A = (L, P, I_sem, O, C, V)
```

where `L` is a finite typed language/search space, `P` is a finite executable program in `L`, `I_sem` is the public interpreter, `O` is the set of proof/test obligations, `C` is the certificate/proof/trace set, and `V` is an independent verifier. The full PCCP-H spec also includes repair metadata `R` and bookkeeping metadata `M`; omitting them here only strengthens lower-bound comparisons because their lengths would be additive.

Fix a public prefix-free encoding and define

```text
L(A) = L(P) + alpha L(O) + beta L(C) + gamma L(lib)
```

for fixed nonnegative `alpha,beta,gamma`. The proofs only use that length is nonnegative and that obligations/certificates do not reduce length.

### 0.5 Distortions And Rate Functions

For intervention distribution `Mu_int`, define functional distortion

```text
D_func(A;F_w,Mu_int) = Pr_{(x,q,i) ~ Mu_int}[I_sem(P,x,q,i) != F_w(x,q,i)].
```

For exact finite verification, assume `Mu_int` has full support over the checked domain. Then `D_func=0` iff there are no counterexamples.

A fixed-length reconstruction code of rate `r` is an arbitrary pair

```text
Enc : X_space -> {0,1}^r
Dec : {0,1}^r -> X_hat.
```

It need not be coordinate-separable, linear, a lookup table, or a direct field-copying scheme. Equal-weight surface reconstruction distortion is

```text
D_rec(Enc,Dec;P_obs) = E_{X ~ P_obs}[d_X(X,Dec(Enc(X)))],
```

where `d_X` is unnormalized Hamming distance over declared surface bits. The reconstruction rate-distortion function is

```text
R_rec(D) = min r such that some Enc,Dec have D_rec <= D.
```

The PCCP rate-distortion function is

```text
R_PCCP(D) = min L(A)
            subject to D_func(A;F,Mu_int) <= D
            and V(A) accepts the required obligations.
```

`K_PCCP(F | L,V)=R_PCCP(0)`. `K(F)` denotes language-relative shortest executable decision-rule length, excluding proof overhead; it is not an absolute Kolmogorov-complexity claim.

## 1. Observational-Equivalence Impossibility

### Theorem 1.1: Explicit Finite Observational-Equivalence Pair

There exist two finite SCMs `w_forward` and `w_reverse` such that:

1. `P_obs^{w_forward}(X) = P_obs^{w_reverse}(X)`.
2. `F_{w_forward}(x,q,i) != F_{w_reverse}(x,q,i)` for some `(x,q,i)`.
3. No function of `P_obs(X)` alone can identify the correct interventional target function for both worlds.

#### Construction

Both worlds have binary endogenous variables `A,B in {0,1}` and one fair binary exogenous variable.

World `w_forward`:

```text
U ~ Bernoulli(1/2)
A := U
B := A
X := (A,B)
```

World `w_reverse`:

```text
U ~ Bernoulli(1/2)
B := U
A := B
X := (A,B)
```

The query set contains `q_B = "return B after the intervention"`. The intervention set contains `i_0 = do(A:=0)`. For observed `x=(a,b)`, define `F_w(x,q_B,i_0)` as the counterfactual value of `B` after applying `i_0` while holding fixed the unique factual exogenous assignment consistent with `x`.

#### Proof

In `w_forward`, `A=U` and `B=A`, so

```text
Pr[X=(0,0)] = 1/2
Pr[X=(1,1)] = 1/2
Pr[X=(0,1)] = 0
Pr[X=(1,0)] = 0.
```

In `w_reverse`, `B=U` and `A=B`, so the same four probabilities hold. Hence the observational distributions are identical.

Evaluate the intervention at `x=(1,1)`. In `w_forward`, the unique factual exogenous assignment is `U=1`. After `do(A:=0)`, equation `B:=A` remains active, so `B=0`. Thus

```text
F_{w_forward}((1,1),q_B,do(A:=0)) = 0.
```

In `w_reverse`, the unique factual exogenous assignment is also `U=1`. After `do(A:=0)`, equation `B:=U` remains active, so `B=1`. Thus

```text
F_{w_reverse}((1,1),q_B,do(A:=0)) = 1.
```

Let `T` be any deterministic map from observational distributions to proposed target functions. Since the two observational distributions are identical, `T` returns the same proposed function `H` for both worlds. At the disputed triple, `H` has one value. If it is `0`, then `H` is wrong for `w_reverse`; if it is `1`, then `H` is wrong for `w_forward`. These are the only binary cases. Therefore no deterministic function of `P_obs` alone identifies the correct `F_w` for both worlds.

For a randomized procedure whose output distribution depends only on `P_obs`, let `p` be the probability that it outputs `1` at the disputed triple. Its error probability at that triple is `p` on `w_forward` and `1-p` on `w_reverse`; the larger is at least `1/2`. Randomization therefore also cannot give a uniform guarantee from `P_obs` alone.

This proves the theorem.

### Corollary 1.2: Observational Reconstruction Cannot Guarantee Interventional Correctness

Any learning or compression rule whose input and objective are functions only of `P_obs(X)` and surface reconstruction distortion cannot be guaranteed to return an artifact that is interventionally correct for all finite SCMs.

#### Proof

Such a rule receives the same input and has the same objective in `w_forward` and `w_reverse`, because their observational distributions are identical. Therefore its output distribution is the same in both worlds. By Theorem 1.1, any same output distribution fails on the disputed intervention triple with probability at least `1/2` in at least one of the two worlds. This proves the corollary.

### What Part 1 Does And Does Not Prove

Part 1 proves a causal identifiability limitation: observational data alone does not determine all interventional target functions.

It does not prove that every reconstruction model fails in every world. Reconstruction can preserve the right causal variable when that variable is observationally identifiable, high-rate enough to store, or weighted strongly enough in the objective.

## 2. Nuisance-Entropy Rate-Distortion Gap

Part 2 proves a length gap between surface reconstruction and functional PCCP compression. The lower bound allows arbitrary fixed-length block encoders and arbitrary decoders.

### 2.1 World Family `W_m`

For each `m >= 1`, define a finite world with

```text
C in {0,1}       causal bit
N in {0,1}^m     nuisance vector
S in {0,1}       spurious bit
```

The observational distribution is

```text
C ~ Bernoulli(1/2)
N ~ Uniform({0,1}^m), independent of C
S := C
X := (C,N,S).
```

The query set contains `q_y = "return the target decision"`. The intervention set contains

```text
id
do(N:=n')
do(S:=s')
do(C:=c').
```

The target rule is

```text
F_m((c,n,s),q_y,i) = c_i,
```

where `c_i=c'` if `i=do(C:=c')`, and otherwise `c_i=c`. Thus the target is invariant to nuisance and spurious interventions and covariant with causal interventions.

### 2.2 Lemma: General Nuisance Reconstruction Lower Bound

Let `N ~ Uniform({0,1}^m)`. Let `M` be any message taking at most `2^r` values, and let `N_hat` be any deterministic function of `M` with values in `{0,1}^m`. If

```text
E[d_H(N,N_hat)] <= Delta
```

for `0 <= Delta <= m/2`, then

```text
r >= m * (1 - h_2(Delta/m)),
```

where `h_2(p) = -p log p - (1-p) log(1-p)`.

In particular, exact nuisance reconstruction (`Delta=0`) requires `r >= m`. Fixed fractional distortion `Delta=delta m` with `delta < 1/2` requires `Omega(m)` bits. Constant nonzero expected error gives `m - O(log m)`, not generally `m - O(1)`.

#### Proof

Because `N` is uniform, `H(N)=m`. Since `M` has at most `2^r` values, `H(M) <= r`. Since `N_hat` is a deterministic function of `M`, `I(N;N_hat) <= H(M) <= r`. Therefore

```text
m = H(N) = I(N;N_hat) + H(N | N_hat) <= r + H(N | N_hat),
```

so

```text
r >= m - H(N | N_hat).
```

Let `E_vec = N xor N_hat`. Given `N_hat`, the pair `(E_vec,N_hat)` determines `N`, so

```text
H(N | N_hat) = H(E_vec | N_hat) <= H(E_vec).
```

Let `E_j` be the `j`-th error bit and `p_j=Pr[E_j=1]`. Subadditivity gives

```text
H(E_vec) <= sum_j H(E_j) = sum_j h_2(p_j).
```

Also `sum_j p_j = E[d_H(N,N_hat)] <= Delta`. Since `h_2` is concave and increasing on `[0,1/2]`, Jensen's inequality gives

```text
sum_j h_2(p_j) <= m h_2((1/m) sum_j p_j) <= m h_2(Delta/m).
```

Combining the inequalities yields

```text
r >= m - H(N | N_hat) >= m - m h_2(Delta/m).
```

This proves the lemma.

### 2.3 Theorem: Reconstruction Rate Lower Bound For `W_m`

For `W_m`, any fixed-length reconstruction code

```text
Enc : X -> {0,1}^r
Dec : {0,1}^r -> X
```

with expected equal-weight surface Hamming distortion at most `Delta` satisfies

```text
r >= m * (1 - h_2(Delta/m))
```

for `0 <= Delta <= m/2`. In particular,

```text
R_rec(0) >= m.
```

Exact surface reconstruction is achievable with `m+1` bits by storing `(C,N)` and reconstructing `S=C`, so

```text
R_rec(0) = m + O(1).
```

#### Proof

Let `X=(C,N,S)` and `X_hat=Dec(Enc(X))`. Let `N_hat` be the nuisance field projected from `X_hat`. Equal-weight surface Hamming distortion includes nuisance-bit errors, so

```text
E[d_H(N,N_hat)] <= E[d_X(X,X_hat)] <= Delta.
```

The message `M=Enc(X)` has at most `2^r` values, and `N_hat` is a deterministic function of `M`. Lemma 2.2 gives the lower bound.

For achievability at exact distortion, use

```text
Enc(C,N,S) = (C,N)
Dec(C,N) = (C,N,C).
```

This uses `m+1` bits and reconstructs `X` exactly because `S=C` in the observational distribution. Thus `R_rec(0)=m+O(1)`.

### 2.4 Theorem: PCCP Upper Bound Independent Of Nuisance Entropy

Assume the public observation schema exposes, or a public decoder `decode_C` computes, the causal field `C` from `X`. Let `K(decode_C)` be its description length. Let `g` be the target rule with description length `K(g)`. For `W_m`, `g(c)=c`.

There exists a PCCP artifact `A_m` with exact functional distortion zero on the full finite intervention domain and

```text
L(A_m) <= K(g) + K(decode_C) + K(apply_C_intervention) + proof_overhead.
```

If the schema and intervention grammar are public side information, and the proof system can express non-use of `N` and `S` without enumerating all nuisance values, the right-hand side is independent of `m`.

#### Proof

Construct the executable program:

```text
input: x, q, i
c := decode_C(x)
if i is do(C:=c') then c := c'
return g(c)
```

Check the intervention cases.

1. If `i=id`, the program returns `g(c)`, which is `F_m(x,q_y,id)`.
2. If `i=do(N:=n')`, the target leaves `C` unchanged. The program ignores `N` and returns `g(c)`.
3. If `i=do(S:=s')`, the target leaves `C` unchanged. The program ignores `S` and returns `g(c)`.
4. If `i=do(C:=c')`, the target returns `g(c')`. The program replaces `c` by `c'` and returns `g(c')`.

These cases exhaust the declared intervention grammar, so the program is correct on the full finite domain.

The obligations can be:

```text
O_1: decode_C returns the causal field C.
O_2: the program terminates on all finite inputs.
O_3: the program does not read N.
O_4: the program does not read S.
O_5: do(N:=n') and do(S:=s') leave the target decision invariant.
O_6: do(C:=c') replaces c by c' before applying g.
```

A certificate can be a typed proof or symbolic trace of the four cases. It need not list all `2^m` nuisance assignments. The verifier can check syntactic non-use of `N` and `S`, type correctness of `decode_C`, and the finite intervention cases. Therefore the stated length bound holds.

### 2.5 Corollary: Omega(m) Reconstruction/PCCP Length Gap

For `W_m`, under exact surface reconstruction,

```text
R_rec(0) = m + O(1),
```

while

```text
R_PCCP(0) <= K(g) + K(decode_C) + K(apply_C_intervention) + proof_overhead.
```

If the PCCP terms are bounded independently of `m`, then

```text
R_rec(0) - R_PCCP(0) = Omega(m).
```

#### Proof

The reconstruction equality is Theorem 2.3. The PCCP upper bound is Theorem 2.4. Subtracting an `m`-independent quantity from `m+O(1)` gives a linear gap for all sufficiently large `m`.

### 2.6 Budgeted Reconstruction Intuition And Its Limit

The old 3-variable sketch is useful as intuition but not as the general theorem.

Let

```text
A ~ Bernoulli(epsilon), epsilon < 1/4
N ~ Uniform({0,1}^m)
S := A
X := (A,N,S).
```

A coordinate code that stores `N` exactly and decodes `A_hat=0`, `S_hat=0` has expected surface Hamming distortion `2 epsilon`. A coordinate code that stores `A` and only `m-1` nuisance bits has expected nuisance distortion at least `1/2`. Thus, among those coordinate-style codes, equal-weight reconstruction prefers the nuisance-only code when `2 epsilon < 1/2`.

The stronger statement

```text
Every arbitrary m-bit reconstruction-optimal encoder must discard A
```

is not proved here and should not be assumed. Arbitrary encoders can allocate codewords asymmetrically to rare states. The robust result is Lemma 2.2 and the exact/low-distortion rate lower bound, not the coordinate-code intuition.

### 2.7 What Part 2 Does And Does Not Prove

Part 2 proves that any low-distortion surface reconstruction code for `m` independent nuisance bits needs rate growing with `m`, even with arbitrary fixed-length block encoders. It also proves that an exact PCCP artifact can ignore nuisance and have length independent of `m` under the stated schema and proof assumptions.

It does not prove that reconstruction always discards causal variables. It does not cover all generative MDL methods. It does not prove `m-O(1)` at arbitrary nonzero constant expected Hamming distortion. It does not prove that a synthesizer can efficiently find the short PCCP artifact.

## 3. Restricted Verifier Discovery

Verifier discovery is the PCCP-B extension. The fully open-world version is not proved here. This section proves one small exact-learning theorem and a wrapper theorem.

### 3.1 Exact-Learning Mapping

Let `E_trace` be a finite trace space. A verifier clause is a Boolean predicate

```text
v : E_trace -> {0,1}.
```

A verifier class is `CalV={v_theta : theta in Theta}`.

| Exact learning object | PCCP-B object |
|---|---|
| Target concept `v*` | Target verifier clause or obligation |
| Instance `e` | Program trace, intervention case, counterexample, proof state |
| Membership query | "Does trace e satisfy the target obligation?" |
| Equivalence query | "Is proposed verifier v_hat equivalent to v*?" |
| Counterexample | Finite trace where v_hat(e) != v*(e) |
| Hypothesis class | Declared verifier grammar |
| Learned concept | Checkable obligation added to O or V |

This mapping is exact only when the oracle answers the target obligation rather than a noisy proxy.

### 3.2 Theorem: Monotone-Conjunction Verifier Discovery

Let each trace `e` have a feature vector `phi(e) in {0,1}^d`. Assume the target verifier has the form

```text
v_S(e) = AND_{j in S} phi_j(e)
```

for an unknown subset `S` of `{1,...,d}`.

Assume feature-realizable membership access: for every vector queried below, the learner can produce a trace with exactly that feature vector, and an oracle returns `v_S` on that trace.

Then `S` can be identified exactly using `d+1` membership queries and no equivalence queries.

#### Algorithm

1. Query the all-ones vector `1^d`. Under the theorem assumptions, the answer is `1`.
2. For each `j`, query `z^(j)`, where `z^(j)_j=0` and `z^(j)_k=1` for `k != j`.
3. Put `j` in `S_hat` exactly when the oracle returns `0` on `z^(j)`.
4. Output `v_hat(e)=AND_{j in S_hat} phi_j(e)`.

#### Proof

Fix an index `j`. If `j in S`, then the conjunction contains `phi_j`; since `z^(j)_j=0`, the target returns `0`. If `j notin S`, every required feature has value `1` in `z^(j)`, so the target returns `1`. Therefore the query on `z^(j)` is negative exactly for indices in `S`. The algorithm recovers `S_hat=S`, and the output conjunction equals the target on every trace. The query count is one all-ones query plus one query per feature, so it is `d+1`.

### 3.3 Theorem Schema: PCCP-B Inherits Exact-Learning Query Bounds

Let `CalV` be a verifier class with an exact learner `Learn_CalV` that identifies every target verifier `v* in CalV` using at most `Q_M(s)` membership queries and `Q_E(s)` equivalence queries for representation size `s`.

Assume PCCP-B has membership and equivalence-query access to the same target verifier oracle over the same finite trace space. Then PCCP-B can identify `v*` with the same query counts, plus the cost of translating the learned representation into PCCP obligations and verifier code.

#### Proof

PCCP-B runs `Learn_CalV`. Every membership query made by `Learn_CalV` is forwarded to the verifier oracle. Every equivalence query is forwarded to the same oracle, and any returned counterexample trace is passed back to `Learn_CalV`. By the assumed correctness of `Learn_CalV`, the returned representation is exactly `v*` after at most the stated query counts. The wrapper does not add learning queries; it only compiles the representation into an obligation or verifier clause.

### 3.4 Richer Classes Not Proved Here

The following are not proved in this document: DFA or regular trace obligations via Angluin-style learning, Horn/ICE invariant learning, bounded Hoare-triple discovery, metamorphic relation discovery from arbitrary finite grammars, and causal-parent invariance discovery under partial interventions. They may instantiate Theorem 3.3 only after importing a specific exact-learning theorem and checking its oracle assumptions.

### 3.5 What Part 3 Does And Does Not Prove

Part 3 proves restricted verifier discovery for monotone conjunctions and a general wrapper theorem for exact-learnable classes. It does not prove open-world verifier discovery, choice of verifier grammar, avoidance of learned-verifier Goodhart failures, discovery of intervention families, or transfer beyond the finite trace space.

## 4. Combined Separation Statement

### Theorem 4.1: Interventional Functional Compression Separation

There exist finite world families with arbitrarily large nuisance entropy `m` such that:

1. Observational distributions do not determine the correct interventional target function across all finite SCMs.
2. Exact or sufficiently low-distortion equal-weight surface reconstruction requires rate growing with `m`.
3. The target function has an exact PCCP artifact whose length is independent of `m`, under the stated public-schema and symbolic-proof assumptions.

For `W_m` specifically,

```text
R_rec(0) = m + O(1)
R_PCCP(0) <= K(g) + K(decode_C) + K(apply_C_intervention) + proof_overhead.
```

If the PCCP terms are bounded independently of `m`, then

```text
R_rec(0) - R_PCCP(0) = Omega(m).
```

#### Proof

Claim 1 is Theorem 1.1 and Corollary 1.2. Claim 2 is Theorem 2.3. Claim 3 is Theorem 2.4. The displayed length gap is Corollary 2.5.

## 5. Explicit Limits And False Statements

### 5.1 Proved In This Draft

1. **Observational-equivalence impossibility:** finite SCMs can have identical observational distributions and different interventional target functions.
2. **General nuisance reconstruction lower bound:** arbitrary fixed-length reconstruction encoders need rate `m(1-h_2(Delta/m))` to reconstruct `m` uniform nuisance bits to expected Hamming error `Delta`.
3. **Exact reconstruction/PCCP length gap:** exact surface reconstruction has rate `m+O(1)` in `W_m`, while exact PCCP functional compression can be independent of `m`.
4. **Restricted verifier discovery:** monotone-conjunction verifier clauses can be learned with `d+1` membership queries under feature-realizability.

### 5.2 Conjectured Or Conditional

1. **Open-world verifier discovery:** [CONJECTURE: requires a verifier grammar, grounding oracle, intervention source, and anti-Goodhart validation.]
2. **DFA/Horn/ICE/metamorphic verifier discovery inside PCCP-B:** [CONJECTURE: requires importing the relevant exact-learning theorem and matching its query model.]
3. **Efficient synthesis of the shortest artifact:** [CONJECTURE: this draft constructs a short artifact but does not prove that a bounded CPU procedure will find it efficiently.]
4. **Local repair from counterexamples:** [CONJECTURE: requires modular dependency cones and stable proof interfaces; not automatic from being proof-carrying.]

### 5.3 False If Stated Broadly

1. **"Reconstruction always drops causal variables."** False. If the causal variable is high-entropy, reconstruction-salient, needed to reconstruct descendants, or heavily weighted in the surface distortion, reconstruction may preserve it.
2. **"m-O(1) rate is required for every nonzero constant expected Hamming distortion."** False. Lemma 2.2 gives `m-O(log m)` for constant nonzero expected bit error and `Omega(m)` for fixed fractional distortion.
3. **"PCCP is a new synthesis algorithm."** False as stated. The theorem supports a functional-compression artifact contract. It does not claim novelty over CEGIS, ILP, SyGuS, DreamCoder, symbolic regression, causal discovery, proof-carrying code, or invariant/spec mining.
4. **"A learned verifier is automatically aligned."** False. A learned verifier can become another proxy unless grounded by exact counterexamples, interventions, or human-auditable obligations.

## 6. Narrative Gate

### 6.1 Which Parts Are Proved, Conjectured, Or False?

Proved:

- observational-equivalence impossibility;
- reconstruction nuisance lower bound for arbitrary fixed-length block codes;
- exact reconstruction/PCCP `Omega(m)` length gap for `W_m`;
- monotone-conjunction verifier discovery under exact membership access.

Conjectured or conditional:

- open-world verifier/decomposition discovery;
- efficient synthesis of shortest artifacts;
- local repair in non-modular artifacts;
- richer exact-learning verifier classes until their query models are imported.

False if overstated:

- reconstruction always fails;
- exact `m-O(1)` lower bound at arbitrary nonzero constant distortion;
- PCCP as a novel primitive algorithm;
- learned verifiers as inherently trustworthy.

### 6.2 Is The Proved Portion Enough For A Meaningful Claim?

Yes, for a theorem-bounded claim:

```text
In finite worlds, observational surface reconstruction can be provably misaligned with interventional function preservation, and nuisance entropy can force an Omega(m) reconstruction-length cost that a proof-carrying causal program avoids.
```

No, for the full moonshot claim. The proof does not show that PCCP-H beats strong synthesis systems or neural-tool agents, and it does not solve verifier discovery outside restricted exact-learning classes.

### 6.3 Gossip-Magazine Summary

The reconstruction model memorized the wallpaper. The causal program found the light switch. When the room was secretly rewired, the wallpaper expert still looked busy, but the tiny proof-carrying rule knew what actually changed the outcome.
